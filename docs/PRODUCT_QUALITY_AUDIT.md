### P0 — 直接损害体验

- 列车普通结果必须所有人确认，没有统一服务端截止时间；一人不点击就停住，断线后也没有定时自愈。
- 阿瓦隆手机私密身份区固定在底部，占据中央任务区，当前行动可能被遮挡。
- 列车手机车厢占据首屏，确认/行动区在下方，底部手牌抽屉进一步遮挡。策划时主任务不在视野里。
- 骆驼操作区继承固定网格，窄屏操作与下注仍拥挤；大块赛道与实际操作脱节。
- 整个 gameMount 的 filter 动画会改变固定浮层的包含块；全页闪亮并不能说明具体发生了什么。

### P1 — 明显影响商业完成度

- 大厅像介绍网页而不是游戏馆，主要依靠文字；所有房间都叫“探险队集合”。
- 阿瓦隆与女巫镇都像深色 dashboard：重复圆角面板、字号小、信息重复、Emoji 主视觉。
- 列车玩家缩成首字徽章，名字过度截断；行动卡只靠符号区别，事件信息与棋盘空间没有联系。
- 骰城六边形棋盘在桌面首屏下方被截断，下注按钮小；同款面板与大量金色边框削弱了赌场场景。
- 女巫镇移动端记录位于手牌之前；固定角色与冗长等待文案压低了当前任务优先级。
- 缺少全局声音管理；骰城独立创建 AudioContext，女巫镇独立语音，静音、音量与多标签行为未统一。
- 重大揭示与终局仍大量依赖普通框体；没有清晰区分普通反馈、重大结果和终局演出。

### P2 — 精修

- 统一短按、选中、不可用、键盘焦点；不能只靠颜色传递行动资格。
- 减少无意义无限发光/弹跳、手牌每次重绘重播发牌动画。
- 原创矢量纹章、牌背、行动符号和场景装饰替换重点区域 Emoji；保留语义文本。
- 补充终局回看、辅助说明、音效层级、低动态模式、可读停留和移动端安全区。

## 设计方向（实现约束）

平台是“私人桌游俱乐部”：暖纸、墨色、编辑式标题、清楚的座位与任务。不把所有游戏套成一种界面。

| 游戏 | 独立方向 | 高情绪时刻 |
| --- | --- | --- |
| 骆驼 | 赛场海报、沙丘、彩色木质驼队、投注票券 | 开骰 / 驼队移动 / 赛段派彩 / 冲线与领奖 |
| 阿瓦隆 | 古典纹章、蚀刻圣杯、夜蓝与旧金、誓约卷轴 | 身份启封 / 圆桌票型 / 匿名任务 / 刺杀与阵营揭晓 |
| 骰城 | 装饰艺术赌场、墨绿毡布、象牙骰、刻印筹码 | 骰盅开局 / 骰群进场 / 平局取消 / 派彩与财富终榜 |
| 列车 | 铁路票据、荒野版画、木板与铁件、通缉令 | 暗牌揭开 / 跨车移动 / 枪击与抢劫 / 回合事件 / 悬赏终榜 |
| 女巫镇 | 木刻小镇、蜡封、档案纸、煤黑与血锈 | 指控审判 / 身份揭示 / 阴谋易手 / 夜袭 / 黎明终局 |

平台统一字阶 12/14/16/20/28/40；中文正文优先可读，装饰小字不得承担规则。间距 4/8/12/16/24/32/48；按钮可触区域至少 44px。板材阴影最多两层，模态一致管理焦点与关闭，游戏纹章不代替文字。

Motion：L1 100–200ms，L2 200–400ms（路径移动可延至 700ms），L3 400–1200ms 加内容阅读停留，L4 分段演出后稳定展示。动画和阅读时间分开；reduced-motion 保留内容与顺序，禁用位移和闪光。

声音：UI / gameplay / flow / major 四层，用户手势解锁；全局静音与音量；相同事件去重、隐藏页面静默、重大音效压低普通提示；声音从公开呈现事件触发，不参与游戏规则。
