## 视觉与游戏手感验收原则

- 每次改造必须在真实浏览器中检查桌面端和移动端，不得只依赖源码判断或自动测试。
- 游戏应建立清晰且一致的 typography、按钮、玩家面板、卡牌、棋盘、弹层、状态颜色和动效语法。
- 回合开始、行动提交、公开揭示、结算、受击或得分、淘汰和胜利都应有可理解且有节奏的反馈。
- 动画时长必须服务于观察和理解；文字密集、骰子、派彩、揭示和规则阶段必须留出足够停留时间，适合时提供手动确认。
- 视觉升级不得破坏秘密信息边界、规则正确性、响应式交互、断线恢复或现有测试。
